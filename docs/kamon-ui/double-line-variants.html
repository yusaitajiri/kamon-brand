Double line variants

The second round of the double line study, on the same Kikitori screen: six ways to frame the cards (D) and six ways to draw the rule (E). Every column has the plain primary with its inner line. All the added lines are neutral border colors, so the accent still marks only what can be acted on.

D. The double line frames the cards

Like the frame around the motif: the card's border and a second line inside it.

E. The double line as a rule

The double line drawn as a horizontal rule, as in a ledger or a printed form. Cards stay single.
